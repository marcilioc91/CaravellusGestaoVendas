# Caravellus — frontend

Angular 21 interface and Electron desktop shell of Caravellus.
Full documentation: [README](../README.md) (English) · [README.pt-BR](../README.pt-BR.md) (Português).

```bash
npm install
npm start            # dev server on http://localhost:4200 (the backend must be running on :8080)
npx ng build         # production build in dist/caravellus-frontend
npm run electron     # desktop shell loading the build in dist/
```

The Windows installer is produced by `build-release.bat` at the repository root.
